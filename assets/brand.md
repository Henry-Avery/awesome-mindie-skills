# Brand assets

The mark connects five nodes into an M-shaped path, representing connected steps in inference engineering. The banners pair the catalogue title with its Ascend inference scope and community audience. The original artwork is editable SVG and uses the repository's CC0-1.0 license.

| Asset | Intended use |
|---|---|
| [logo.svg](logo.svg) | Square mark; 128 × 128 viewBox. Display at 80–96 px in a standalone README header. |
| [logo-mono.svg](logo-mono.svg) | Single-color mark for light backgrounds and print. |
| [banner-light.svg](banner-light.svg) | Light README banner; 1200 × 320 viewBox. |
| [banner-dark.svg](banner-dark.svg) | Dark README banner; 1200 × 320 viewBox. |

The README uses a picture element to select the dark banner when supported, with the light banner as fallback. The adjacent Markdown title and introduction retain the name and purpose as readable text.

## Palette

- Teal: `#0F766E` for the primary mark.
- Violet: `#7C3AED` for a small accent; `#C4B5FD` on dark backgrounds.
- Slate: `#0F172A` for text or dark backgrounds.
- Light text: `#F8FAFC`.

Keep the node path recognizable at 24 px. Use SVG for source assets and export a raster copy only when a destination requires one. For a later social preview, use a separate 1280 × 640 composition with the same mark, title, and subtitle.
